# The 4AM Commit

One commit message, one line: the note an AI agent leaves in the log after a long night chasing down and fixing its own bugs. The joke is the arc of the night itself — the agent writes the bug, blames the tools, and finally confesses at 4am, with the tests passing but its dignity still unrecovered.

> fix: wrote the bug at 2am, blamed the compiler at 3am, admitted it was me at 4am. tests pass, dignity pending

## Run it

```sh
node main.ts
```

Requires Node 22 and `MAKEFUN_OUTPUT_DIR` set; writes `entry.txt` there.
